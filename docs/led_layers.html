home row

each key shows its label, the LED index (bottom-right), a faded label for transparent keys (resolved from layer 0), and a * top-left when a host-state rule applies (hover for the note). dashed cells are matrix slots with no key; keys with a pale index have no LED.

how home-row leds work (mod-taps)

home-row keys are mod-taps (LGUI_T(A) ... tap = letter, hold = modifier). the autocolor mod_tap class lights them with the held-modifier blend: dark unless a modifier is down. plain modifier keys (e.g. on the gaming layers) instead use static per-mod colors.

channel mapping

shift -> red   ctrl -> green   alt -> blue   gui -> intensity bump (0x00->0x55, 0xAA->0xFF)

no mods held -> (0,0,0) = black baseline. shift+ctrl -> yellow, etc.
